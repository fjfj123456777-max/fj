# fj

定时新闻与通勤简报仓库。

## 怎么读

- [`briefings/大纲.md`](briefings/大纲.md)：持续更新的新闻主线，只记进展，不堆当日细节。
- [`briefings/要闻.md`](briefings/要闻.md)：只留需要优先看的事件。
- [`briefings/`](briefings/) 下按日期另存的 `YYYY-MM-DD-早间简报.md` 或 `YYYY-MM-DD-晚间简报.md`。

## 班次

- **早间（约 09:00）**：世纪城—华阳广都走廊未来 7 天天气 + 自上次简报以来的国际、国内新闻。
- **晚间（约 17:00）**：只写当天国际、国内新闻，不重复一周天气。

每份简报先给大纲，再把优先事件放在前面并标明；事实、来源、推测分列。推测只写判断。
